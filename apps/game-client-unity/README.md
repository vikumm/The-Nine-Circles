# Unity Client Bootstrap

This folder contains the VS-001 Unity client skeleton.

Environment note:

- Unity Hub is installed locally.
- Unity 2021.3.26f1 is available and is recorded in `ProjectSettings/ProjectVersion.txt`.

Scope for VS-001:

- keep the client as an empty Unity project shell;
- do not implement login, networking, movement, combat, inventory, prediction or UI;
- do not place authoritative game rules in the client.

Future work:

- VS-003 may add generated protocol code.
- VS-007 and later tasks may add client bootstrap only after server-side gates are satisfied.

VS-003 note:

- protocol contracts are generated by `packages/contracts-proto`;
- no Unity gameplay, networking, prediction or UI code is added in this task;
- imported generated C# for Unity must remain client intent code only.
